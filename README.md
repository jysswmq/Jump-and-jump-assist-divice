CN: 鼠标触发器使用说明
1. 双击运行 鼠标触发器.exe，会弹出一个黑色窗口（请勿关闭）。
2. 操作：
   - 按下鼠标中键（滚轮）→ 记录起点
   - 按下鼠标右键 → 记录终点
   - 程序自动计算距离，并按 config.txt 中的系数换算为毫秒，自动长按左键。
3. 修改系数：
   - 关闭程序（按 ESC），编辑同目录下的 config.txt，修改“系数=0.0036”中的数字。
   - 保存后重新运行程序，新系数生效。
4. 退出：按键盘 ESC 键。
5. 程序运行期间会打印状态信息，方便观察。

EN: Mouse Trigger Usage Instructions
1. Double-click to run Mouse Trigger.exe, which will pop up a black window (do not close it).
2. Operation:
 - Press the mouse middle button (scroll wheel) → Record the starting point
 - Press the right mouse button → Record the endpoint
 The program automatically calculates the distance and converts it to milliseconds based on the coefficients in config.txt, then performs a long press of the left button automatically.
3. Modify the coefficient:
 - Close the program (press ESC), then edit the config.txt file in the same directory and modify the number in "coefficient=0.0036".
 After saving, restart the program to apply the new coefficients.
4. Exit: Press the ESC key on the keyboard.
5. Status information will be printed during program execution for easy observation.
